# サーキット会場マップ

ライブサーキットを回るための、スマホ向けの静的HTMLマップ(非公式・個人制作)。
いまの対応イベント: 下北沢にて'26 (2026-12-05)

- 地図: 出典：国土地理院 淡色地図(地理院タイル)。Leaflet で表示
- タイムテーブル・写真: 各イベントの公式サイトより

## ファイル構成

```
index.html                アプリ本体(イベント共通)
venues.js                 会場台帳(イベントをまたいで使い回す)
events/list.js            対応イベント一覧(先頭が既定)
events/<イベントID>/
  event.js                イベント情報(名前・日付・公式サイト・独自会場)
  timetable.js            タイムテーブル(必須)
  profiles.js             アクトのプロフィール(任意)
  images.js               アーティスト写真の対応表(任意)
```

`index.html?e=<イベントID>` でイベントを切り替えます(省略時は一覧の先頭)。

## 新しいイベントの追加

1. `events/<イベントID>/` を作り、`event.js` と `timetable.js` を置く
   - `timetable.js`: `const TIMETABLE = { "会場名": [{ s: "12:00", e: "12:30", n: "出演者" }, ...] }`
     - `c: 1` はお笑いなどの別枠、`ev: 1` はパレードなど選択対象外の催し
2. タイムテーブルの会場名が `venues.js` の `name` か `aliases` と一致するか確認する
   - 一致しない会場は、地図を開くと「地図に出せない会場」と表示される
   - 常設の会場は `venues.js` に追加、仮設ステージなどは `event.js` の `extraVenues` に書く
   - 同じ建物の会場は `bldg` を同じ値にすると1つのピンにまとまる
3. `events/list.js` に追加する

座標は国土地理院のジオコーダ(`https://msearch.gsi.go.jp/address-search/AddressSearch?q=住所`)で住所から取得できます。
